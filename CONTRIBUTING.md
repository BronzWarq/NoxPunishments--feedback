# Contributing to NoxPunishments Issues

Thank you for helping improve NoxPunishments.

- Search existing issues before creating a new one.
- Use the form that best matches your report.
- Keep each issue focused on one bug, question, or feature request.
- Include exact steps to reproduce bugs and describe both expected and actual behavior.
- Keep discussion constructive and provide follow-up details when maintainers request them.
- Do not post secrets, private server addresses, player UUIDs, or personal information. Redact logs, configuration files, and screenshots before sharing them.

This repository is an issue tracker only; do not submit plugin source code or binary builds here.
