# NoxPunishments Issues

This is the public issue tracker for **NoxPunishments**, a Minecraft moderation plugin for Paper, BungeeCord/Waterfall, and Velocity.

This repository contains issue forms and reporting guidance only. It does not contain the plugin source code or downloadable builds.

## Open an issue

- Choose **Bug report** for something that is not working.
- Choose **Feature request** to suggest an improvement.
- Choose **Question or setup help** for configuration and usage questions.

Before opening an issue, search existing reports for the same problem. Please submit one issue per bug or request and include enough detail for the maintainers to understand it.

For bug reports, include the NoxPunishments version, platform and server version, Java version, storage type, reproduction steps, expected behavior, and actual behavior. Attach only the relevant log excerpt or configuration settings.

## Protect your privacy

Issues are public. Never post database passwords, API keys, tokens, private server addresses, player UUIDs, personal information, or unredacted configuration and logs. Remove identifying details from screenshots before attaching them.

## Supported platforms

- Paper 1.16.5 and newer
- BungeeCord and Waterfall
- Velocity 3.4 and newer (Java 21 required)

SQLite is available for standalone storage. Shared MySQL storage is used for network deployments.
